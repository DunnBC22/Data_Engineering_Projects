# E-Commerce Website Logs - KNIME Pipeline

## Description

- This pipeline:
    - Retrieves data from MongoDB collection & convert it to table
    - Transforms data:
        - Remove $oid
        - Create autogenerated incrementing column (id)
        - Clean up spelling
        - Convert Age to integer values
        - Convert AccessedDateTime to Date data type & Extract date & time parts
        - OneHotEncode (OHE) Discrete Features
        - Handle AccessedDate & Extract date parts
    - Sends transformed data to MySQL table (that was just created)


## Dataset Source
https://www.kaggle.com/datasets/kzmontage/e-commerce-website-logs
